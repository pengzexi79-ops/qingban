# 亲伴开发存档

本目录保存成员每个 AI 开发保存点的事实记录。记录由仓库 Skill：

```text
$qinban-team-collaboration
```

根据当前 Git diff 生成。

规则：

- 每次保存点创建独立文件，不多人追加同一个日志；
- 按日期分目录，档案与对应代码进入同一分支和 PR；
- 只写实际变更、测试和影响，不把计划或占位写成完成；
- 已合并档案不覆盖，错误通过新增更正档案处理；
- 同一任务上下文中的同一非存档变更状态使用内容指纹去重，继续修改后才生成下一份档案；
- 不记录密钥、Cookie、真实用户数据或大段源码。

“保存点”是一次可以独立描述的 AI 修改批次。Skill 无法监听成员在 AI 之外的每次编辑器按键，但成员再次调用 AI、准备提交或创建 PR 时，AI必须自动补齐本次存档。
