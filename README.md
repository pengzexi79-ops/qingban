# 青伴 QingBan

> 把重要的陪伴，放在身边。

青伴是一款面向日常情绪陪伴的轻量 Web App 初版。它把 **AI 好友、微信式会话、长期记忆** 放在一条简单主链路里：创建一个你愿意聊天的 AI 好友，和 TA 说话，让重要的细节被记住。

本仓库当前只实现前端演示，不包含真实 AI 服务端、账号体系、云端同步或任何第三方模型密钥。

## 当前 MVP

- **会话**：微信风格的会话列表、未读筛选、搜索、聊天窗口
- **AI 好友**：创建、编辑、删除 AI 好友；设置名字、关系、介绍、性格、说话方式和初次见面话术
- **本地模拟对话**：发送消息后生成轻量本地回复，覆盖问候、疲惫、难过、焦虑、记忆、喜欢等常见表达
- **长期记忆库**：按 AI 好友管理记忆，支持添加、编辑、删除、搜索和类型筛选
- **主动消息**：手动邀请 TA 主动说句话，并提供本地定时主动消息演示；支持夜间安静时间
- **个人与设置**：修改昵称和签名，控制主动消息、通知、夜间安静、低亮模式
- **本地数据管理**：导出 JSON、恢复演示数据、清空本机数据
- **响应式界面**：桌面端侧栏 + 双栏会话，移动端底部导航 + 聊天页

## 产品取舍

本版刻意只保留「创建角色 → 聊天 → 记忆」这条核心体验，不接入与当前前端 MVP 无关的模型网关、工作流编排、计费、知识库、语音和复杂后台规划。

用户提供的产品文档中涉及的品牌、云服务和后端研发内容，仅作为产品理念与后续方向参考；本项目以用户本次明确要求的 **“青伴、前端优先、先做可用框架”** 为准，不沿用原项目已有的阿里云 / 百炼产品定义。

## 技术栈

- **Vue 3**：通过 CDN 加载，无构建步骤
- **原生 CSS**：暖白、低饱和紫蓝与暖橙的轻量陪伴界面
- **localStorage**：保存 AI 好友、聊天记录、记忆和本地设置
- **原生 HTML / JavaScript**：保持初版简单，便于继续改造

## 本地运行

```bash
git clone https://github.com/pengzexi79-ops/qingban.git
cd qingban
python -m http.server 8765
```

然后访问 <http://localhost:8765>。

也可以使用任意静态服务器打开项目根目录。由于页面通过 CDN 加载 Vue，首次打开需要网络连接；项目本身不包含 API Key。

## 数据说明

所有演示数据默认只保存在当前浏览器的 `localStorage` 中：

- 刷新页面会保留本机数据
- 「导出数据」可以下载 JSON 备份
- 「清空本机数据」会删除当前浏览器中的青伴数据；清空后刷新页面不会自动恢复种子数据
- 「恢复演示数据」会重新写入示例 AI 好友、会话和记忆

请不要把真实隐私内容放入尚未接入加密和云端权限控制的演示环境。

## 借鉴的开源项目

青伴采用了成熟聊天产品中已被验证的交互思路，但保持独立实现，没有直接复制下列项目的源码、品牌资源或视觉资产：

- [NextChat](https://github.com/ChatGPTNextWeb/NextChat)（MIT）：轻量聊天布局、跨端适配和设置体验
- [LibreChat](https://github.com/danny-avila/LibreChat)（MIT）：多会话、角色配置和聊天管理思路
- [LobeHub](https://github.com/lobehub/lobehub)：角色 / Agent 组织、记忆和工作区理念，仅作产品研究参考
- [Open WebUI](https://github.com/open-webui/open-webui)：成熟的聊天工作区与模型会话组织方式，仅作产品研究参考

以上项目的许可证和附加条款各自独立，后续如需引入代码或资源，必须先逐项审核许可证、版权声明和品牌使用限制。本仓库当前代码、UI 和数据层均为青伴独立实现。

## 当前限制与后续方向

- 当前 AI 回复是本地规则模拟，不是真实大模型对话
- 没有登录、云端同步、多设备同步和服务端数据隔离
- 主动消息是浏览器打开期间的本地定时演示，不是系统推送
- 记忆目前是可编辑的本地数据，后续再接入真实的记忆提取、确认和检索链路
- 后续可在不破坏当前前端交互的前提下接入后端 API、流式回复、语音和更严格的隐私保护
